# Provenance du jeu d'or

Ces 20 avis et leurs annotations sont une proposition rédigée avec Codex le 14 novembre 2026.
Ils ne sont pas présentés comme les dix avis rédigés par chacun des membres demandés par le TP.
Le groupe doit les relire, confirmer/corriger les étiquettes et ajouter ses propres exemples.
Les erreurs franches observées sont conservées et expliquées dans erreur_connue.
L'abstention n'est pas comptée comme une bonne classification. Aucun ajustement du modèle
n'est réalisé sur ces avis. Le seuil 0,60 est celui proposé dans le cours.
